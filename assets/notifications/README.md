# Dvites admin notification sounds

Place your custom new-order sound here:

- **Default file:** `new-order.mp3`
- **Default URL:** `/assets/notifications/new-order.mp3`

Replace `new-order.mp3` with your own short MP3 (recommended 0.3–1.5 seconds). The admin dashboard plays this file when a new order is detected.

You can also set a custom path or full URL in the admin **Notification Sound** settings panel.

# Pichwai Royal — Dvites Wedding Invitation

Standalone digital wedding invitation template for Dvites.

## Structure

```
templates/pichwai-royal/
├── index.html
├── assets/
│   ├── css/style.css
│   ├── js/app.js
│   ├── images/
│   ├── video/
│   └── audio/
└── README.md
```

## Customization

Edit `WEDDING_CONFIG` at the top of `assets/js/app.js` for couple names, dates, venue, parents, events, gallery, story, and WhatsApp number.

## Preview bar

`index.html` includes a temporary **Dvites Preview** strip (marked in HTML/CSS comments). Remove `#dvites-preview-bar` and `#dvites-preview-bar-styles` before client delivery.

## Local preview

Serve the repo root and open:

`/templates/pichwai-royal/`

- **Dvites name:** Heavens Alight
- **Slug:** `heavens-alight`

## Architecture

| Layer | File | Role |
|-------|------|------|
| Backup | `index-source.html` | Unmodified ShaadiPath preview snapshot |
| Production | `index.html` | Localized Dvites demo (generated by `build.js`) |
| Styles | `assets/css/style.css` | Full template styling (~85 KB minified) |
| Fonts | `assets/css/fonts.css` + `assets/fonts/*.ttf` | Cormorant Garamond + Jost (local) |
| Logic | `assets/js/script.js` | All animations & config hydration |
| Dvites | `assets/js/dvites-runtime.js` | ICS calendar + WhatsApp safety |
| Assets | `mirror.js` | One-time downloader from ShaadiPath CDN |
| Build | `build.js` | Rebrand + path rewrite + buy bar |

## Animation architecture

- **Intro:** Canvas particles (dust, mist, burst) + CSS cork hold/pop + layered champagne PNG stack
- **Hero:** Muted looping MP4 + text reveal + scroll cue
- **Invite:** 3D CSS perspective cover flip + staggered `.inv-reveal` text
- **Events:** Dynamically rendered from config; alternating cupid decorations
- **Story:** IntersectionObserver line reveals + petal sprites
- **Gallery:** Sticky scroll track; frame transforms driven by scroll progress (`data-count` 1–4)
- **TTK:** Cards rendered from `thingsToKnow[]` with icon map
- **RSVP:** Background video + reveal animations
- **Countdown:** Live timer to `couple.date`

## Wedding config

Single JSON block (`#wedding-config`) drives couple, invite, events, story, gallery, thingsToKnow, rsvp, music, calendarUrls. `script.js` hydrates DOM on load.

## Issues encountered

1. **`Meet_the_couple_bg.webp` and `Gallery_Bg.webp`** returned HTTP 404 from ShaadiPath CDN at extraction time. Created gradient WebP placeholders matching section color palette. Overlays (`.st-atm-*`, `.gl-atm-*`) preserve atmosphere.
2. **User catalogue mockup** was not present in the workspace; `thumbnail.png` was generated from `hero_poster.webp` (390×844 crop). Replace with attached mockup when available.
3. **Wrangler dev** failed locally due to compatibility-date mismatch; static verification used `python3 -m http.server 8788`.
